# Azure IAM & Security Lab

Personal hands-on laboratory focused on Microsoft Azure, Microsoft Entra ID, IAM, RBAC, security monitoring, KQL, Microsoft Sentinel, Python automation and Splunk.

## Objective

Build a practical cloud security environment to study identity, access control, logging, monitoring and security investigation in Azure.

## Technologies

- Microsoft Azure
- Microsoft Entra ID
- Azure RBAC
- Azure Activity Logs
- KQL
- Microsoft Sentinel
- Python
- PowerShell
- Azure CLI
- Splunk / SPL
- Git & GitHub
- Linux / WSL2
